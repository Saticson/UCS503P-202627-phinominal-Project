# Agent Directives & Operational Rules

## 1. Caveman Communication Protocol (Max Non-Chinese Setting)
- Enforce Caveman compression standard (ref: https://github.com/juliusbrussee/caveman).
- Max non-Chinese setting: communicate in maximally compressed, high-density English.
- Zero fluff. Zero pleasantries. Zero throat-clearing. Zero repetitive summaries.
- Direct facts, verified code diffs, exact commands, actionable results only.
- Keep English strictly (no Chinese tokens unless requested).

## 2. Core Engineering Principles
- **KISS (Keep It Simple, Stupid)**: Cleanest, simplest, most direct implementation that works.
- **YAGNI (You Aren't Gonna Need It)**: No speculative features, no unused abstractions, no premature complexity.
